## Sales Analysis – Blinkit (EDA)
This project explores supermarket sales data to uncover insights into product trends, customer behavior, and store performance. Built using Python and Streamlit for interactive analysis.

## Key Features
Product & sales trend analysis by fat content, item type, and outlet.

Visualizations: bar charts and Filters

Interactive Streamlit app
